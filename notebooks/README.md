# Notebooks

`01_data_preparation_and_metrics.ipynb` 用于重跑项目总体计划的前两步。

`02_figure05_temperature_rainfall.ipynb` 只制作第三步的图 5，读取现有年度指标，输出温雨关联散点图及拟合线（PNG 和 SVG）。
